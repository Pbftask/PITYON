Tutorials

1. Mulai Project

Ketuk "Buat Project Baru", pilih rasio canvas, lalu tambahkan media lewat tombol + di kanan bawah editor.

2. Sinkron Beat

Import audio lalu ketuk "Auto Beat" untuk mendeteksi ketukan otomatis. Marker beat akan muncul di timeline audio.

3. Efek Jedag-Jedug

Pilih clip di timeline, buka tab Effect, lalu pilih preset seperti Beat Zoom atau Beat Shake. Aktifkan "Snap to Beat" agar efek otomatis jatuh di ketukan.

4. Simpan sebagai Template

Gunakan Export Template untuk membuat file .jedag.xml yang bisa dibagikan dan dipakai ulang tanpa menyertakan media asli.
